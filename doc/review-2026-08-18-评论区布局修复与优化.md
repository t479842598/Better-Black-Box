日期：2026-08-18　范围：src 下评论预览 / 详情页工具栏 / 只看楼主功能

## 一、问题根因

### 1.1 元素重叠（"看楼主"与勾选区域）
评论预览头部渲染的"只看楼主"按钮类名为 `better-comment-preview__only-owner-toggle`，但全部开关样式（`display:inline-flex; gap:6px` 等）只挂在 `.better-comment-preview__cy-toggle` 上。按钮缺少 flex 化导致其内部开关圆点 `<span class="cy-toggle-switch">` 退化为 inline 元素——`width/height` 不生效，圆点容器塌缩为 0 尺寸，`::after` 小圆点相对 0 尺寸定位后直接压到"只看楼主"文字上，形成重叠。

### 1.2 按钮布局被误删
工作区存在**未提交改动**（相对 git HEAD v1.7）：评论预览工具栏被从
「三段式排序（默认|最新|作者优先）＋ 📊 观点总结 ＋ 只看楼主 ＋ 屏蔽CY」
削成只剩「只看楼主」，详情页工具栏也被削成只剩「只看楼主」，且 `link-page.js` 的改动未重建进 `src/content.js`（运行态仍为旧结构），源码与产物漂移。

## 四、综合优化建议（本次代码审查发现）

1. **开关类控件样式约定**：`.cy-toggle-switch` 依赖父按钮 `display:inline-flex` 才有正确尺寸；后续新增同类"开关+文字"控件时，必须同时为按钮补 `display:inline-flex; align-items:center; gap:6px`，否则会重现本次重叠。
2. **`renderCyToggle` 命名**：函数实际渲染整个工具栏（排序＋观点总结＋屏蔽CY），名不副实，建议后续重命名为 `renderCommentToolbar`（涉及多文件，本次为缩小改动面未执行）。
3. **孤儿存储数据**：`better-xiaoheihe-comment-preview-only-owner` 存储键已从枚举中移除，但用户浏览器中残留的旧值无害（不再读取）；如需彻底清理可在未来版本加一次性迁移。
4. **模块片段校验方式**：`src/content/*.js` 为跨文件拼接片段（如 feed.js 承接上一模块的箭头函数体），单独 `node --check` 会误报语法错；请以 `node scripts/rebuild-bundles.js --check`＋`node --check src/content.js` 为准。
5. **发布提醒**：`dist/` 为 gitignore 的打包目录，本次未动；发布前需 `node scripts/package-crx.mjs` 重新打包并同步 `manifest.json` 版本。
6. **既有小问题（未在本次范围内处理）**：`scheduleKeywordFiltersRefresh` 用 rAF＋120ms setTimeout 双触发重刷（HEAD 既有，属防御性写法）；`getLinkPageCommentOriginalIndex` 用 DOM dataset 缓存原始序号，逻辑正确。
